# Ganar es Perder

## Descripción
Juego 2D de casino con poderes. Incluye minijuegos como Blackjack y Tragamonedas con modificadores especiales que alteran las reglas y la jugabilidad.

## Género
Casino / Roguelite de minijuegos

## Plataforma objetivo
PC (Windows / Mac)

## Tecnologías
- Unity 2D
- C#

## Cómo ejecutar el proyecto
1. Tener instalado Unity 2022.x o superior
2. Clonar o descargar el repositorio
3. Abrir el proyecto desde Unity Hub
4. Cargar la escena principal ubicada en `Scenes/`
5. Presionar Play
